Scope covers the established C# src CLI with the v7 argument parser and managed Git backend. The priority platforms are macOS arm64 and Ubuntu 26.04 arm64. Windows is the final platform gate.

**83 acceptance rows** · 8 matched · 58 partial · 6 open · 6 decision · 4 excluded · 1 deferred

The [machine-readable checklist](PARITY-CHECKLIST.json) maps 42 CLI option entries, 59 configuration property paths, 33 JSON variables, 7 strategies and 15 CI providers. A surface entry can map to several behaviors.

## How to close a row

Run the relevant live tests against the pinned oracle on both priority platforms and record the candidate revision. Compare version values and types, streams, exit status, generated files and repository state as applicable. Include failure, boundary and interaction cases appropriate to the row. The linked results come from the checkpoints named in the evidence. Ported unit tests support those comparisons.

A decision row stays unresolved until the expected behavior is recorded and tested. The release gate requires closure of all in-scope rows and a complete run of the agreed matrix. See the [CLI option index](CLI-COMPATIBILITY.md) for lookup by command and flag.

- **Matched** — The stated, bounded behavior has live pinned-C# evidence on both priority platforms at the linked checkpoint.
- **Partial** — Some cases are evidenced. The gap describes the remaining acceptance work.
- **Open** — No sufficient acceptance evidence is mapped.
- **Decision** — A known or proposed difference needs an explicit compatibility decision.
- **Excluded** — Outside the agreed replacement scope.
- **Deferred** — Scheduled after the priority-platform work.
